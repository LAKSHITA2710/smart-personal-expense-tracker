# Smart Personal Expense Tracker — Project Report

## 1. Project Title

**Smart Personal Expense Tracker**

## 2. Student

**LAKSHITA**

## 3. Project Starting Date

**1 September 2026**

## 4. Project Type

**C++ Application Development**

## 5. Problem Statement

Students often record expenses manually, making it difficult to categorize spending, calculate totals, and understand monthly spending patterns. A simple offline application is needed to record, manage, search, and summarize personal expenses.

## 6. Objectives

- Provide an easy way to record daily expenses.
- Organize expenses by category.
- Calculate total spending.
- Provide category-wise spending summaries.
- Preserve records using local file storage.

## 7. Methodology

The project is implemented as a menu-driven C++ console application. An `Expense` structure stores the date, category, description, and amount of each transaction. A vector stores expense records while the application is running. File handling is used to save records to `expenses.txt` and load them when the application starts. Separate functions are used for adding, displaying, calculating, summarizing, and searching expenses.

## 8. Technologies Used

- C++
- Standard Template Library (STL)
- File handling
- Command-line interface

## 9. Expected Outcome

A working offline expense tracker that can maintain expense records, calculate total spending, and provide category-wise summaries.

## 10. Sustainable Development Goal Alignment

The project aligns with **SDG 12 – Responsible Consumption and Production**. Tracking expenses can improve awareness of personal consumption and encourage more responsible use of resources.

## 11. Outcome Achieved

The prototype successfully records expenses, displays stored records, calculates total expenses, generates category-wise summaries, searches by category, and stores data locally for future use.

## 12. Conclusion

The Smart Personal Expense Tracker demonstrates how C++ can be used to solve a practical day-to-day problem. The project reinforces programming fundamentals including structures, vectors, functions, strings, searching, formatted output, and file handling.

## 13. Future Scope

The application can later be extended with a graphical interface, monthly charts, budget limits, alerts, CSV/PDF export, and user authentication.
